# Marchander AI — Design System

## Design Direction

Marchander AI should feel like a modern AI commerce product: dark, premium, conversational, and highly interactive without sacrificing clarity.

## Visual Principles
- Dark-first interface
- Strong contrast
- Minimal visual clutter
- Clear negotiation states
- Voice interaction as a primary action
- Product imagery remains the visual focus
- Motion should communicate state, not distract

## Suggested Color Tokens

Black and white


## Core Screens
1. Landing page
2. Product listing
3. Product details
4. Negotiation interface
5. Deal confirmation
6. Cart
7. Checkout
8. Merchant dashboard (later)

## Negotiation UI
The negotiation screen should contain:
- Product image/name
- Listed price
- Seller minimum price hidden from buyer
- Current offer
- AI counter-offer
- Negotiation history
- Microphone button
- Text input fallback
- Accept / Counter / Reject actions
- Round/status indicator

## Interaction States
- Idle
- Listening
- Transcribing
- Thinking
- Countering
- Accepted
- Rejected
- Error

## Motion
Use short transitions for:
- Voice listening
- AI processing
- New offer arrival
- Deal confirmation
- Cart price update

Avoid excessive animation during active negotiation.

## Responsive Design
Prioritize mobile first because voice negotiation is naturally suited to mobile commerce. Desktop should provide a richer product + negotiation split layout.
